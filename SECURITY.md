# 安全问题怎么报告 / Reporting security issues

## 中文

适用范围：网站 dontblink.community、它读取的数据和代币清单，以及相关合约。

**发现漏洞请私下报告。不要开公开 issue，不要在 PR、讨论区或社交媒体上贴细节。**

怎么报告：在本仓库页面点 **Security（安全）** 标签 → **Report a vulnerability（报告漏洞）**，写清楚：

- 影响什么（合约地址、页面、包的版本）
- 怎么复现
- 你看到的影响

我们会在这份私下报告里和你沟通。修复发布之前，请不要公开。

如果看不到 "Report a vulnerability" 按钮：开一个只写"需要私下报告安全问题"的 issue，**不要写任何细节**，我们会联系你。

本项目目前没有漏洞赏金计划，提交报告不代表会获得报酬。

## English

Scope: the dontblink.community website, the data and token list it serves, and the related contracts.

**Report vulnerabilities privately. Do not open a public issue, and do not post details in pull requests, discussions or social media.**

How to report: on this repository, open the **Security** tab → **Report a vulnerability**, and include:

- what is affected (contract address, page, package version)
- how to reproduce it
- the impact you observed

We will follow up with you in that private report. Please do not disclose publicly until a fix is released.

If you cannot see the "Report a vulnerability" button, open an issue that only says you need to report a security problem privately, **with no details**, and we will contact you.

This project has no bug bounty program at this time; submitting a report does not entitle you to any reward.
